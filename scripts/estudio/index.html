Referências

Clique para abrir na onda. ou arraste um arquivo para a página: ele é guardado, vira um clipe com nome próprio, é processado e fica pronto para escolher numa arma.

    Clipes do jogo

    Cada clipe é um corte de uma referência, com os seus efeitos. Clique para editar.

      Onda — nenhuma referência aberta

      Arraste na onda para escolher o trecho; arraste as bordas para ajustar. ▶ Trecho é a audição rápida (sem efeitos); ▶ Prévia toca como vai ficar no jogo, com todos os efeitos.

      Efeitos: tom, velocidade, esticar, compressor, equalização, eco…

      Armas — qual som toca em cada uma

      Escolha o clipe de cada arma, ajuste ganho, altura (pitch: menor = mais grave e mais longo) e duração máxima, e ouça no ritmo de tiro da arma (▶▶). Arma sem clipe usa o som sintetizado de sempre. O lança-chamas e a motosserra têm som contínuo próprio e ainda não aceitam amostra.

      ArmaClipeGanhoPitchMáx (s)Ouvir
