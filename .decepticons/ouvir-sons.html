OUVIR OS SONS

Clique para ouvir. Cada botão toca na hora; clique de novo para repetir. Se um botão não faz nada, o arquivo ainda não foi gerado (rode npm run sons ou npm run vozes).

O que eu preciso que você diga: quais sons você aprova, quais troca (e por qual das referências da última seção) e se o volume de algum está alto ou baixo demais. Quem julga é o seu ouvido.
